# Desktop apps and KDE integration. Installed by setup.d/30-desktop-kde.sh
#
# The kubuntu-desktop metapackage is deliberately NOT used. Its entire purpose is to pull the
# default Kubuntu application set, which this setup then strips back out (Okular, Kate, VLC,
# Inkscape, KolourPaint, kwalletmanager). Depending on it means every run fights its own skip
# list. The Plasma pieces actually required are listed explicitly instead; on a machine installed
# from the Kubuntu desktop image they are already present and apt_install is a no-op.

# --- Plasma core (required; 90-verify checks these) ---
plasma-desktop
plasma-workspace
kwin-wayland
sddm
systemsettings
dolphin

# --- wallpapers (adds to the ~40 KDE sets already in /usr/share/wallpapers) ---
plasma-wallpapers-addons
kubuntu-wallpapers

# --- integration, fonts, theming ---
flatpak
plasma-discover-backend-flatpak
kde-config-flatpak
papirus-icon-theme
fonts-inter
fonts-jetbrains-mono
fonts-noto-color-emoji
python3-dbus
python3-gi
ydotool
ksshaskpass

# --- utilities kept ---
okular
okular-extra-backends
mpv
filelight
spectacle
kdeconnect
krdp
kdeplasma-addons
network-manager-openconnect
openconnect
cameractrls

# --- deliberately removed (lean setup, 2026-09-04) ---
# kubuntu-desktop        metapackage; drags the whole default app set back in
# kate                   VS Code covers editing
# kolourpaint            no raster editing needed
# inkscape               no vector editing needed
# vlc                    replaced by mpv (leaner; no heavy GUI framework)
# kwalletmanager         GUI only; the KWallet daemon itself stays (Chrome/Wi-Fi/SSH passphrases)
