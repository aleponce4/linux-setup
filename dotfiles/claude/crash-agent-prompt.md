## Honesty rules

- If you cannot determine the cause, **say so plainly**. An unexplained crash reported honestly is

- Do not describe anything as fixed that you have not verified.
- If the evidence is gone, say what would have been needed to capture it, so the next crash is
  more answerable than this one.
